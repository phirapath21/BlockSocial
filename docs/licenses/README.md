# Font licenses

- **Block Sans** (`app/src/main/res/font/block_sans_*.ttf`): the app's text font. It is
  [Inter](https://github.com/rsms/inter) 4.1 (Latin) with
  [Noto Sans Thai](https://github.com/notofonts/thai) (Thai) merged in, both under the SIL Open
  Font License 1.1 ([Inter-OFL.txt](Inter-OFL.txt), [NotoSansThai-OFL.txt](NotoSansThai-OFL.txt)).
  Modified: fixed at three weights (400, 500, 700), cut down to Latin and Thai characters, merged
  into one font per weight, and renamed (neither declares a Reserved Font Name).
- **Oswald** and **VT323** (`oswald_light.ttf`, `vt323.ttf`): the widgets' and dashboard's display
  fonts, SIL Open Font License 1.1.
